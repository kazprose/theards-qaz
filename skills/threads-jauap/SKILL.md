# Жауап пен дәйексөз

Threads-те жауап — ең ауыр сигнал. Басқаның постына жазған мазмұнды жауап
сол автордың аудиториясына көрінудің ең қысқа жолы.

## Алдымен: профильді оқы

```python
import sys; sys.path.insert(0, ".")
from lib import profil_oqy
p = profil_oqy()   # None болса — профиль әлі жоқ
```

Профиль бар болса, регистрді содан ал — қайта сұрама.
Жоқ болса, түпнұсқа посттың регистріне қарап шеш.

## Алдымен: жауап па, дәйексөз бе?

| Таңдау | Қашан |
|---|---|
| **Жауап** | түпнұсқаға тікелей қатысты, автормен сөйлесесің, қосымша контекст керек емес |
| **Дәйексөз** | өз аудиторияңа көрсеткің келеді, ой түпнұсқадан асып кетеді, өз позицияңды қоясың |

Күмәндансаң — **жауап**. Дәйексөз көрінуге ұмтылу ретінде оқылуы мүмкін,
әсіресе келіспеген жағдайда.

**Келіспегенде әрқашан жауап жаз, дәйексөз емес.** Дәйексөзбен келіспеу —
өз аудиторияңды біреуге қарсы шығару, ол қазақ тіліндегі кіші ортада тез
жанжалға айналады.

## Процесс

### 1. Түпнұсқаны ал

```python
import sys; sys.path.insert(0, ".")
from lib import url_talda
print(url_talda(url))
```

Постың **мәтіні** керек. Бандлда Threads-тен автоматты тарту жоқ, сондықтан
мәтінді пайдаланушыдан сұра. Мазмұнын болжама.

### 2. Не қосатыныңды тап

Жауап үш нәрсенің бірін қосуы керек:

| Түрі | Мысал |
|---|---|
| **Тәжірибе** | «Бізде де солай болды, бірақ себебі басқа екен: …» |
| **Нақты дерек** | «Бұл жерде бір сан бар: …» |
| **Басқа бұрыш** | «Мен мұны екінші жағынан көрдім: …» |

Осы үшеуінің бірі жоқ болса, **жауап жазба**. «Керемет!», «Келісемін»,
«Дұрыс айтасыз» — ешкімге ештеңе бермейді, автор да оны есіне сақтамайды.
Пайдаланушыға осыны ашық айт.

### 3. Жаз

- **1-3 сөйлем.** Ұзын жауап оқылмайды.
- Автордың сөзін қайталама. Ол өз жазғанын біледі.
- Сұрақпен аяқтауға болады, бірақ күштеме.
- Регистр түпнұсқаға сай: автор «сен» десе, сен де солай.
- Кеңсе тілінсіз
  ([`../../references/til-tazalygy.md`](../../references/til-tazalygy.md)).

### Келіспегенде

- Адамға емес, **ойға** қарсы шық.
- Өз тәжірибеңнен баста: «Менде басқаша болды» > «Сіз қателесіп тұрсыз».
- Кекесін жүрмейді. Threads — X емес, ал қазақ тіліндегі орта кіші: бүгін
  ұрысқан адаммен ертең жұмыс істеуің мүмкін.

### 4. Тексер

```bash
python3 -m lib.audit "жауап мәтіні"
```

Жауапта хэштег керек емес. Эмодзи — көп дегенде біреу.

### 5. Мақұлдау және шығару

```python
from lib import kartochka, jariyala
print(kartochka(turi="jauap", mati=draft, nysana_url=url))
```

Мақұлдағаннан кейін:

```python
natije = jariyala("jauap", mati=draft, nysana_url=url)
```

**Жауап пен дәйексөз әрқашан қолмен қойылады.** Себебі олар басқа адамның
постына байланатын бөлек пост, ал автоматты жариялау қате нысанаға түсу
қаупін тудырады. `lib/jariyalau.py` мұны кодта да бекіткен:
`QOLDAN_GANA = {"jauap", "dayekshe"}`.

Сондықтан нәтиже әрқашан көшіріп-қоюға дайын блок болып қайтады, оған қоса
түпнұсқа постың сілтемесі беріледі.

## Шығару пішімі

```
## Шешім: жауап / дәйексөз
{неге солай}

## Не қосамыз
{тәжірибе / дерек / басқа бұрыш}

## Драфт
{мәтін} ({N} таңба)

## Қою реті
1. {сілтемеге} өт
2. мәтінді жауап ретінде қой
```

## Не істемейміз

- Мазмұны жоқ жауап жазбаймыз.
- Түпнұсқа постты оқымай жауап құрастырмаймыз.
- Дәйексөзбен келіспеушілік жарияламаймыз.
- Мақұлдаусыз ештеңе шығармаймыз.
