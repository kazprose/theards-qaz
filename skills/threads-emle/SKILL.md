# Емле, әліпби және транслитерация

Механикалық, автоматты тексерілетін нәрселерге жауап береді. Стиль мен тон —
`threads-redaktor` шеберлігінің ісі.

## 1. Гомоглиф тексеру

Ең маңызды әрі ең жиі жіберілетін қате. Латын `i` мен кирилл `і` экранда
бірдей көрінеді, бірақ іздеу оларды бөлек таңба деп санайды.

```bash
python3 -m lib.emle "мәтін"
```

Табылса — **бірден түзе**, талқыламай:

```python
import sys; sys.path.insert(0, ".")
from lib import gomoglif_tuzetu
print(gomoglif_tuzetu(mati))
```

Функция тек **аралас** сөзді түзетеді. `Claude`, `AI`, `startup` сияқты таза
латын сөздері сол күйі қалады — олар заңды кодты ауыстыру.

Пайдаланушыға не өзгергенін көрсет: көзге бірдей көрінгендіктен, ол
өзгерісті байқамайды.

## 2. Әліпби үлесі

`lib/emle.py` қазаққа тән әріптердің (`ә ғ қ ң ө ұ ү һ і`) үлесін есептейді.

| Үлес | Мағынасы |
|---|---|
| 8-15% | қалыпты қазақ мәтіні |
| 3-8% | кірме сөз көп, немесе аудармаға жақын |
| <3% | мәтін іс жүзінде қазақша емес |

Үлес төмен болса, себебін тап: аударма синтаксисі ме
([`../../references/til-tazalygy.md`](../../references/til-tazalygy.md)),
әлде тым көп орысша термин бе
([`../../references/kod-auystyru.md`](../../references/kod-auystyru.md))?

Бұл көрсеткіш — **сигнал**, үкім емес. IT тақырыбындағы пост табиғи түрде
төмен үлеспен шығады.

## 3. Жиі шатасатын әріптер

Скрипт таппайды, сондықтан қолмен қара:

| Жұп | Ереже |
|---|---|
| `қ`/`к`, `ғ`/`г` | қалың дауысты сөзде `қ`/`ғ`, жіңішкеде `к`/`г` |
| `ұ`/`ү` | `ұ` қалың (ұзақ), `ү` жіңішке (үй) |
| `і`/`и` | `і` — төл дауысты (іш), `и` — кірме (идея) |
| `х`/`һ` | `һ` тек: һәм, қаһарман, гауһар, шаһар |

## 4. Кірме сөзге жалғау

- **Латын әрпімен жазылса — дефис арқылы:** `AI-ды`, `PR-ы`, `Threads-ке`,
  `API-мен`. Дефиссіз (`Threadsке`) — қате.
- **Кириллмен жазылса — тікелей:** `дедлайнға`, `фичаны`, `релизден`.
- **Үндестік соңғы буынға қарай:** `дедлайнға` (қалың), `релизге` (жіңішке),
  `стартапқа`, `фидбекке`.

Толығырақ:
[`../../references/kod-auystyru.md`](../../references/kod-auystyru.md).

## 5. Хэштег таңдау

Threads постқа **бір ғана** хэштег қабылдайды, ал `#қазақстан` мен
`#qazaqstan` — екі бөлек хэштег, аудиториясы да бөлек.

```python
from lib import hashtag_nusqalary
print(hashtag_nusqalary("қазақ тілі"))
# {'кирилл': '#қазақтілі', 'латын': '#qazaqtili'}
```

Қайсысын таңдау:

| Нұсқа | Қашан |
|---|---|
| кирилл | аудиторияң Қазақстанда, қазақша жазады |
| латын | диаспора, халықаралық, IT ортасы |

Екеуін қатар қойма — Threads екіншісін өшіреді.

## 6. Транслитерация

QazLat 2021 (умлаут/бревис нұсқасы):

```python
from lib import latynga
latynga("Қазақстан")                      # Qazaqstan
latynga("Әсем", ascii_qauipsiz=True)      # Asem
```

`ascii_qauipsiz=True` диакритиканы түсіреді (`ä→a`, `ğ→g`, `ñ→n`, `ö→o`,
`ş→s`, `ū/ü→u`) — хэштег пен URL үшін керек.

## 7. Көлем

Threads: 500 таңба. Қазақ тілі жалғамалы, сондықтан бір ой ағылшыннан
~20% көп таңба алады.

Көлем асып тұрса, бірінші кеңсе тіркестерін қара: «жүзеге асыру» (14 таңба)
→ «істеу» (6). Тіл тазалығы тікелей орын үнемдейді.
