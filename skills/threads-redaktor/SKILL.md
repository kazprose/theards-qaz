# Қазақша мәтін редакторы

Дайын мәтінді тірілтеді: кеңсе тілін, орысша кальканы, аударма клишелерін
және AI іздерін алып тастайды.

## Екі режим

| Режим | Не істейді |
|---|---|
| `--mode taza` (әдепкі) | мәтінді қайта жазады |
| `--mode audit` | тек тексереді, мәтінге тимейді |

Пайдаланушы «тексер», «қарап шық», «жіберуге бола ма» десе — `audit`.
«Түзет», «тазала», «қайта жаз» десе — `taza`.

## Не істемейді

Бұл шеберлік мәтіннің AI детекторынан өтуіне **кепілдік бермейді**, әрі оны
мақсат етпейді. Детекторлар пост көлеміндегі мәтінде тұрақсыз жұмыс істейді,
ал жеңіл қайта жазу оларды алдамайды.

Шын мақсат басқа: **тірі адам оқығанда бөгде естілмеу.** Threads жауапқа
құрылған алаң, ал жасанды естілген пост жауап алмайды.

Пайдаланушы «детектордан өткіз» деп сұраса, осыны ашық айт та, істей алатын
нәрсеңді істе.

## `--mode taza` — қайта жазу

### 1-өтпел. Механикалық

```bash
python3 -m lib.audit "мәтін"
```

Гомоглифті бірден түзе (`lib.gomoglif_tuzetu`) — бұл талқылауды қажет
етпейтін қате.

### 2-өтпел. Кеңсе тілі мен калька

`lib/kalka.py` тапқан әр табылымды **контекске қарап** шеш:

- `болып табылады`, `жүзеге асыру`, `мүмкіндік береді` — әрқашан түзет.
- `негізінде`, `байланысты`, `қатысты` — контексте заңды болуы мүмкін.
  Ресми құжат туралы жазып отырса, қалдыр.

Толық тізім:
[`../../references/til-tazalygy.md`](../../references/til-tazalygy.md).

### 3-өтпел. Құрылым

Скрипт таппайтын, бірақ ең маңызды бөлігі:

| Мәселе | Түзету |
|---|---|
| Ырықсыз етіс («шешім қабылданды») | белсенді етіс («шештік») |
| Баяндауыш ортада | SOV ретіне қайтар |
| 18 сөзден ұзын сөйлем | екіге бөл |
| Есімше тізбегі («-ған», «-ып» үш реттен көп) | сөйлемді бөл |
| Үштік тізбек («тез, оңай және сенімді») | біреуін таңда |

### 4-өтпел. AI іздері

[`../../references/ai-izderi.md`](../../references/ai-izderi.md):

- Бос кіріспе-қорытынды («бүгінгі таңда», «қорытындылай келе») — өшір.
- Жасанды пафос — нақты санмен алмастыр.
- Тым тегіс мойындау («бірақ бұл маған сабақ болды») — ашық қалдыр.
- Эмодзи-тізім — жай жол ауыстыруға көшір.

### 5-өтпел. Артық түзетуден сақтану

Мына нәрселерді **түзетпе**, олар қате емес:

- Сызықша (—) бастауыш-баяндауыш арасында. Постқа біреу — норма.
- Кірме терминдер: «дедлайн», «фича», «релиз». Күштеп аударма
  ([`../../references/kod-auystyru.md`](../../references/kod-auystyru.md)).
- Сөйлем ұзындығын әдейі кезектестіру. Механикалық ырғақ — бұдан да
  айқын із. Сөйлемді мазмұн талап еткенде ғана бөл.
- Автордың өзіндік сөзі, әзілі, диалект нұсқасы.

### 6-өтпел. Соңғы тексеру

Қайта жазғаннан кейін `lib.tolyq()` тағы бір рет.

### Шығару пішімі

```
## Түзетілген мәтін
{жаңа мәтін}

## Не өзгерді
- «{ескі}» → «{жаңа}» — {себебі}
- ...

## Тексеру
{lib.tolyq нәтижесі}
```

Әр өзгерістің себебін жаз. Пайдаланушы келісуі де, келіспеуі де мүмкін —
ол үшін неге өзгергенін білуі керек.

## `--mode audit` — жіберер алдындағы тексеру

Мәтінге **тимейді**, тек есеп береді.

```python
import sys; sys.path.insert(0, ".")
from lib import tolyq
print(tolyq(mati))
```

Оған қоса қолмен қара:

- [ ] Бірінші жол өз бетінше тұрып, ойды жеткізе ме?
- [ ] Бір постта бір ой ма?
- [ ] Сілтеме бірінші жолда тұр ма? (тұрса — көшір)
- [ ] Хэштег біреу ме?
- [ ] Тон аудиторияға сай ма, «сен/сіз» бірізді ме?
- [ ] Нақты сан бар ма, әлде тек сын есім бе?
- [ ] Дауыстап оқығанда тірі естіле ме?

### Шығару пішімі

```
## Жіберуге бола ма: ИӘ / ЖОҚ

## Тоқтататын мәселе
{түзетілмей жіберуге болмайтындар}

## Ұсыныс
{міндетті емес, бірақ жақсартады}

## Тексеру есебі
{lib.tolyq нәтижесі}
```

Қатты қате (гомоглиф, көлем, екі хэштег) болса — «ЖОҚ». Қалғаны — ұсыныс.
