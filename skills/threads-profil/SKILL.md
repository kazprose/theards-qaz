# Дауыс профилі

Бандлдағы негіз. Қалған сегіз шеберлік әр жолы аудиторияны, регистрді,
тақырыпты қайта сұрамай, осы файлдан оқиды.

Файл: `.threads-profil.md` жұмыс бумасында.

## Неге керек

Профильсіз екі мәселе болады:

1. **Қайталанатын сұрақ.** Әр шеберлік «аудиторияң кім?» деп сұрайды.
   Пайдаланушы оны бес рет жазады, алтыншысында басқаша жазады да,
   посттар бір-біріне ұқсамай қалады.
2. **Тексерілмейтін ереже.** «Мен "сен" деп жазамын» деген сөз ешқайда
   жазылмаса, драфтта «сіз» шығып кеткенін ешкім байқамайды.

Профиль екеуін де шешеді. Оның үстіне **регистр мен тыйым салынған
сөздер машинамен тексеріледі** — бұл бандлдағы жалғыз жер, онда профиль
жай нұсқаулық емес, нақты ереже болып істейді.

## Бірінші рет: сұхбат

Профиль жоқ болса (`lib.profil.oqy()` → `None`), пайдаланушыдан сұра.
Бәрін бірден сұрама — **бір-бірлеп**, жауабына қарай нақтылап отыр.

### 1. Кім

> «Не істейсің? Бір сөйлеммен, нақты.»

Жалпылама жауап келсе, нақтылап сұра:

| Келген жауап | Не сұрау керек |
|---|---|
| «технологиялық жоба» | «Нақты не істейді? Кім қолданады?» |
| «маркетингпен айналысамын» | «Өз бизнесің бе, әлде клиентке ме?» |
| «блог жүргіземін» | «Не туралы? Кім оқиды?» |

### 2. Аудитория

> «Кім оқиды? Нақты бір адамды елестет.»

«Бәрі» деген жауап — ең жиі әрі ең зиянды. Оны қабылдама: аудитория жалпы
болса, посттар да жалпылама шығады, ал жалпылама пост жауап әкелмейді.
Мұны ашық айт та, тарылтуға көмектес.

### 3. Регистр — ең маңызды сұрақ

> «Оқырманға "сен" деп жазасың ба, "сіз" деп пе?»

Threads-те **«сен»** табиғи. «Сіз» — ресми бренд аккаунты, мемлекеттік
немесе корпоративтік контекст үшін.

> «Кірме терминдерді қалай жазасың?»

| Нұсқа | Мысал |
|---|---|
| `еркін` | «дедлайнға үлгермедік», «фичаны шығардық» — IT/стартап |
| `шамалы` | қажет терминді ғана қалдырасың |
| `таза қазақша` | терминді де қазақшалайсың |

Күмәндансаң, [`../../references/kod-auystyru.md`](../../references/kod-auystyru.md)
ішіндегі кестені көрсет.

### 4. Бағаналар

> «Қандай 3-4 тақырып туралы тұрақты жазасың?»

Әрқайсысы бір рөл атқаруы керек. Ұсынуға болатын қаңқа:

| Бағана | Не береді |
|---|---|
| Жұмыс | не істеп жатырсың, нақты сандар |
| Пікір | сала туралы көзқарасың |
| Тіл | қазақ тілі туралы байқаулар |
| Адами | таныс сәт, күнделікті бақылау |

**Тіл бағанасы** — қазақша аккаунттың ең күшті құралы, ағылшын
контентінде баламасы жоқ. Ұсын, бірақ таңдауды пайдаланушыға қалдыр.

### 5. Айтпайтын сөздер

> «Қандай сөздер сенің брендіңе жат? Оқысаң, кірпідей тікенектенетін.»

Мысалдар: «үздік», «инновациялық», «синергия», «көшбасшы». Бәсекелестің
аты да кіруі мүмкін.

Бұл тізім **машинамен тексеріледі**, сондықтан нақты сөз жаз, ұғым емес.

### 6. Мысалдар

> «Өзің жазған, дауысыңды дәл көрсететін 2-3 постың бар ма?»

Ең пайдалы бөлім. Ережеден гөрі мысал көбірек үйретеді. Пайдаланушыда
дайын пост болмаса, бұл бөлімді бос қалдыр — кейін толтырады.

## Файлды жазу

```python
import sys; sys.path.insert(0, ".")
from lib import profil_ulgi, profil_jaz
profil_jaz(profil_ulgi())   # үлгіні жазады, содан соң толтырасың
```

Немесе командадан:

```bash
python3 -m lib.profil ulgi > .threads-profil.md
```

Сұхбат нәтижесін үлгінің тиісті бөліміне жаз. Толтырылмаған бөлім қате
шығармайды — жай ғана ескерілмейді.

## Оқу және тексеру

```bash
python3 -m lib.profil          # профильдің қысқаша мазмұны
```

```python
from lib import profil_oqy, profil_saikestik
p = profil_oqy()               # None болса — профиль әлі жоқ
profil_saikestik(draft, p)     # драфт профильге сай ма
```

`lib.tolyq()` мұны өзі істейді: профиль болса, тексеру есебінің 4-бөлімі
профильге сәйкестікті көрсетеді.

## Не машинамен тексеріледі

| Тексеру | Деңгейі | Профиль керек пе |
|---|---|---|
| Бір постта «сен» мен «сіз» араласқаны | **қате** | жоқ |
| Драфттың регистрі профильге қайшы | ескерту | иә |
| Тыйым салынған сөз кездескені | ескерту | иә |

Регистрдің араласуы — профильге тәуелсіз қате: бір постта екеуін қатар
қолдану оқырманға бірден байқалады.

Қалғаны (аудитория, бағаналар, мысалдар) — модель оқитын контекст,
машиналық тексеру емес.

## Жаңарту

Профиль — қатып қалған құжат емес. Мыналарды өзгерткен жөн:

- `threads-natije` бір бағананың тұрақты жақсы жүретінін көрсетсе,
- регистрді саналы түрде ауыстырсаң,
- жаңа мысал пост шықса (ескісінің орнына жаңасын қой).

Профильді өзгерткенде **не өзгергенін айт**: пайдаланушы бұрынғы
нұсқасын ұмытып қалуы мүмкін.

## Не істемейміз

- Пайдаланушының атынан аудитория, бағана немесе мысал ойлап шықпаймыз.
  Ұсыныс береміз, таңдауды ол жасайды.
- «Бәрі» деген аудиторияны үнсіз қабылдамаймыз.
- Профильді сұрамай өзгертпейміз.
- Threads аккаунтының биосын жазбаймыз — бұл профиль ішкі құжат,
  оқырманға көрінбейді.
