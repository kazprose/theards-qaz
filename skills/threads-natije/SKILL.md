# Нәтижені өлшеу

Бандлдағы шеңберді жабатын шеберлік. Қалғандары пост жазады, ал бұл — не
болғанын жазып алады да, бірнеше аптадан кейін **қай формула сенің
аудиторияңда жүретінін** көрсетеді.

## Алдымен: профильді оқы

```python
import sys; sys.path.insert(0, ".")
from lib import profil_oqy
p = profil_oqy()   # None болса — профиль әлі жоқ
```

Профиль бар болса, бағаналарды содан ал — қайта сұрама.
Жоқ болса, тек формула бойынша қорытындыла.

## Неге керек

`references/hook-formulasy.md` ішіндегі 13 формула — **болжам**. Қазақ
тіліндегі Threads корпусы жоқ, сондықтан олардың қайсысы жүретінін ешкім
білмейді. Оны білудің жалғыз жолы — өз постыңды өлшеу.

Осы шеберлікті бірнеше апта қолдансаң, бандл сен үшін болжам айтуды
қойып, **бақылау** айта бастайды.

## Үш ережесі

1. **Сан Threads Insights экранынан, қолмен беріледі.** Бандл ешқандай
   санды өзі тартпайды.
2. **Ешқашан сан ойдан шығарылмайды.** Пайдаланушы санды бермесе, ол
   жазба «өлшенбеген» болып қалады. «Шамамен мың көрсетілім болған
   шығар» деп жазуға болмайды — бір ойдан шыққан сан бүкіл журналдың
   құнын жояды.
3. **Үлгі аз болса, қорытынды жасалмайды.** Бір формула бойынша 5-тен аз
   өлшенген пост болса, сан көрсетіледі, бірақ «мынау жақсы» деген
   қорытынды айтылмайды.

## Үш режим

### `qos` — жаңа постты жазып қою

Пост жарияланғаннан кейін бірден. Формуласымен бірге жазылады, әйтпесе
кейін қай постың қай формуламен жазылғаны ұмытылады.

```bash
python3 -m lib.jurnal qos Q3 jauap "постың алғашқы сөздері"
```

Немесе Python арқылы, толығырақ:

```python
import sys; sys.path.insert(0, ".")
from lib.jurnal import Jazba, jaz
jaz(Jazba(kuni="2026-09-08", formula="Q3", maqsat="jauap",
          turi="post", tanba=312, mati_bas="Қазақша подкаст шығардық…",
          url="https://www.threads.com/@handle/post/KOD"))
```

`threads-post-jazu` шеберлігі постты мақұлдағаннан кейін пайдаланушыға
осыны ұсынуы керек.

### `janart` — сандарды АВТОМАТТЫ тарту (ұсынылатын жол)

`THREADS_TOKEN` бапталған болса, сандарды қолмен теру керек емес:

```bash
python3 -m lib.threads_api janart
```

Журналдағы өлшенбеген жазбалар `url` арқылы Threads-тегі постпен
байланысады да, статистикасы тартылады.

Сондықтан **пост жарияланғанда `url` жазылуы міндетті** — онсыз жазба
API-мен байланыспайды. `threads-post-jazu` шеберлігі мұны істейді.

Токен жоқ болса, төмендегі қолмен әдіске көш.

### `olshe` — сандарды қолмен қосу

Посттан **48-72 сағаттан** кейін. Ертерек қарасаң, пост әлі таралып жатыр.

Пайдаланушыдан Threads Insights экранындағы сандарды сұра:

| Сұрайтын сан | Insights-те қалай аталады |
|---|---|
| көрсетілім | Views / Көрсетілім |
| жауап | Replies |
| репост | Reposts |
| лайк | Likes |
| дәйексөз | Quotes |

Бәрі міндетті емес, бірақ **көрсетілімсіз** ештеңе есептелмейді: барлық
көрсеткіш көрсетілімге бөлінеді.

Сандарды `.threads-jurnal.jsonl` файлындағы сол жазбаға қос:

```json
"olshem": {"korsetilim": 1200, "jauap": 14, "repost": 3, "laik": 40, "dayekshe": 1}
```

### `esep` — талдау

```bash
python3 -m lib.jurnal esep
```

Шығатыны: формула бойынша медиана әрекет үлесі мен жауап үлесі, әрқайсысы
үлгі жеткілікті ме деген белгімен.

### `bolzham` — өз тарихыңнан күтілетін диапазон

```python
from lib import bolzham
print(bolzham("Q3"))
```

```
Q3 форматындағы 12 постың: жауап үлесі 1.4%–3.1%, медианасы 2.1%.
Бұл — өткен нәтиже, кепілдік емес.
```

Диапазон — квартильдер (25%–75%), яғни «әдеттегі» аралық. Ең жақсы мен
ең нашар нәтиже әдейі шетте қалады: шағын аудиторияда бір вирусты пост
диапазонды мағынасыз кеңейтеді.

**Мұны болжам ретінде ұсынба.** Бұл — өткен нәтиже. «Сенің Q3 посттарың
осындай нәтиже берген» деп айт, «бұл пост осындай болады» деп айтпа.
Үлгі 5-тен аз болса, функцияның өзі ескертеді — соны жеткіз.

### `tauekel` — драфт нашар жүргендерге ұқсай ма

```python
from lib import tauekel
belgiler, izah = tauekel(draft)
```

Өлшенген посттарды жауап үлесі бойынша екіге бөліп, әр белгінің
медианасын салыстырады. Драфт нашар жақтың медианасына жақын болса —
белгі береді.

Үш ережесі:

1. **Дерек жеткіліксіз болса, ештеңе айтпайды.** 5 өлшенген посттан
   аз болса, бос тізім мен түсіндірме қайтады.
2. **Айырма 20%-дан аз болса, елемейді.** Ол — шуыл.
3. **Себеп емес, корреляция.** Мұны әрқашан айт: белгі мен нәтиженің
   байланысы кездейсоқ та болуы мүмкін. Функция қайтаратын түсіндірме
   жолын өзгертпей жеткіз.

## Нәтижені қалай оқу керек

Негізгі көрсеткіш — **жауап ÷ көрсетілім**. Барлық әрекетті қосып
жіберсең, лайк саны бәрін көміп кетеді, ал лайк — Threads-тегі ең арзан
сигнал.

Медиана қолданылады, орташа емес: бір вирусты пост орташаны бұрмалайды, ал
шағын аудиторияда ондай пост жиі кездеседі.

### Әр есептен кейін бір шешім шығуы керек

| Не көрінді | Шешім |
|---|---|
| Бір формула тұрақты алда (5+ пост, 20%+ айырма) | оны жиірек қолдан |
| Бәрі шамалас | формула маңызды емес, тақырыпқа көш |
| Бәрі төмен | формула емес, аудитория не уақыт мәселесі |
| Дерек аз | тағы жаз, әзірге қорытынды жасама |

Шешім шықпаса, өлшеудің қажеті болмаған. Есепті көрсетіп қана қоймай,
**нақты ұсыныс** айт.

## Қазақ аудиториясының ерекшелігі

Мұны әр есепте есте ұста:

- **Статистикалық маңыздылық болмайды.** Қазақша жазатын аудитория шағын,
  500 жазылушыда А/Б тестінің математикалық дәлелі шықпайды. Оны қума.
- **Тек үлкен айырмаға сен.** 5-10% — шуыл. ~20%-дан асқан әрі 3-5 рет
  қайталанған айырма — сигнал.
- **Ағылшын бенчмаркімен салыстырма.** 15 жауап қазақша постта жақсы
  нәтиже болуы мүмкін.
- **Жалғыз жарамды салыстыру — өзіңнің өткен айдағы медианаң.**

## Не істемейміз

- Сан ойдан шығармаймыз. Жоқ санды «жоқ» деп жазамыз.
- `bolzham()` нәтижесін болашақ туралы уәде ретінде ұсынбаймыз.
- `tauekel()` белгісін себеп ретінде ұсынбаймыз — ол корреляция.
- Бір посттан заңдылық шығармаймыз.
- «Сала орташасы» деген сан келтірмейміз — қазақ тіліндегі Threads үшін
  ондай дерек жоқ.
- Айырманы бірден формулаға телмейміз: формуламен бірге тақырып та,
  уақыт та өзгереді. Мұны есепте ашық айтамыз.
- Өсу қисығын алға тартпаймыз.
