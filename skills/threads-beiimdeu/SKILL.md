# Бейімдеу: басқа платформа мен басқа тілден

## Алдымен: профильді оқы

```python
import sys; sys.path.insert(0, ".")
from lib import profil_oqy
p = profil_oqy()   # None болса — профиль әлі жоқ
```

Профиль бар болса, регистр мен кодты ауыстыру деңгейін содан ал — қайта сұрама.
Жоқ болса, бейімдеудің тонын пайдаланушыдан сұра.

## Негізгі ереже

**Бұл аударма емес.** Тікелей аударылған мәтін қазақша Threads-те бірден
көрінеді: құрылымы бөгде, ырғағы бөгде, кеңсе тілі толып тұрады.

Дұрыс жол: **түпнұсқадан ойды ал, постты нөлден жаз.**

## Кіріс түрлері

| Қайдан | Басты мәселе |
|---|---|
| LinkedIn | корпоративтік тон, «мен сізбен бөліскім келеді» кіріспесі |
| X (Twitter) | суық, кекесінді тон — Threads-те жүрмейді |
| Блог/мақала | тым ұзын, кіріспе-қорытынды артық |
| YouTube сценарийі | ауызша қайталаулар, «айтып өткенімдей» |
| Ақпарат хат | тізім-тізім, сату тілі |
| Орысша мәтін | калька қаупі — ең үлкені |
| Ағылшынша мәтін | SVO құрылымы, ұзын сөйлем |

## Процесс

### 1. Бір ойды тап

Түпнұсқада бірнеше ой болады. Threads постына **біреуі** ғана сыяды.

Сұрақ: «Мұның ішіндегі ең күшті бір сөйлемі қайсы?» Соны ал, қалғанын тастап
кет. Бәрін сақтауға тырысу — бейімдеудің №1 қатесі.

Бірнеше ой шынымен күшті болса, оларды **бөлек посттарға** бөл, бір постқа
тықпа.

### 2. Түпнұсқа тілін ұмыт

Мәтінді жауып қой да, ойды өз сөзіңмен қазақша айт. Содан кейін ғана
түпнұсқаға оралып, нақты сан мен фактіні тексер.

Бұл қадам міндетті. Түпнұсқа көз алдында тұрса, құрылымы қалып қояды.

### 3. Платформа қалдықтарын өшір

| Қалдық | Не істеу |
|---|---|
| «Мен сізбен бөліскім келеді…» | өшір, бірден мазмұн |
| «🧵 Тред:» / «(1/7)» | Threads олай нөмірлемейді |
| «Толығырақ сілтемеде» | сілтеме бірінші постта болмасын |
| Эмодзи-тізім (✅ ✅ ✅) | жай жол ауыстыруға көшір |
| «Осы туралы не ойлайсыз?» | шын ашық сұраққа айналдыр не өшір |
| «#маркетинг #бизнес #kz» | бір хэштег қалдыр |
| Хештег тізбегі | сол |

### 4. Тонды жылыт

X-тен келсе — кекесінді алып тастап, шақыруға айналдыр.
LinkedIn-нен келсе — корпоративтік бет-пердені сыпыр.

> LinkedIn: «Біздің команда өнімді жүзеге асыру барысында үлкен жетістікке
> қол жеткізді.»
> Threads: «Өнімді шығардық. Екі рет кері қайтардық. Үшіншісінде жүрді.»

### 5. Hook-ты қайта құр

Түпнұсқаның бірінші жолы басқа платформаға есептелген. Threads үшін
формуланы қайта таңда:
[`../../references/hook-formulasy.md`](../../references/hook-formulasy.md).

### 6. Тіл тазалығы

Орысшадан бейімдегенде бұл ең қауіпті жер. Міндетті түрде:

```bash
python3 -m lib.audit "бейімделген мәтін"
```

Аудармадан қалатын тұрақты іздер:

- `болып табылады`, `жүзеге асыру`, `мүмкіндік береді`
- `барысында`, `шеңберінде`, `аталған`
- ырықсыз етіс: «шешім қабылданды» → «шештік»
- ұзын сөйлем: 18 сөзден асса бөл
- үштік тізбек: «тез, тиімді және сенімді»

Толық тізім:
[`../../references/til-tazalygy.md`](../../references/til-tazalygy.md).

### 7. Кодты ауыстыруды реттеу

Түпнұсқа ағылшынша болса, терминдерді қалай беру керек — бірізді шеш:

- Сала термині сол күйі: «дедлайн», «фича», «релиз».
- Күнделікті ұғым қазақша: «сұрақ», «нәтиже», «мәселе».
- Латын әрпімен жазылса, жалғау дефис арқылы: `AI-ды`, `API-мен`.

[`../../references/kod-auystyru.md`](../../references/kod-auystyru.md).

### 8. Көлемге сыйғыз

Қазақ тілі жалғамалы: ағылшыншадан бейімдегенде мәтін ~20% ұзарады.
500 таңбаға сыймаса — ойды азайт, сөзді қысқартпа.

## Шығару пішімі

```
## Түпнұсқадан алынған ой
{бір сөйлем}

## Тасталғаны
{не алынбады және неге}

## Драфт
{мәтін} ({N} таңба)
Формула: {код}

## Тіл тексеруі
{lib.tolyq нәтижесі}
```

Не тасталғанын көрсету маңызды: пайдаланушы түпнұсқаны білгендіктен,
жоғалған бөлікті іздейді.

## Не істемейміз

- Тікелей аудармаймыз.
- Түпнұсқадағы барлық ойды бір постқа тықпаймыз.
- Түпнұсқада жоқ фактіні қоспаймыз.
- Авторлық мәтінді дереккөзін көрсетпей өз атынан бермейміз — түпнұсқа
  басқа адамдікі болса, соны айт.
