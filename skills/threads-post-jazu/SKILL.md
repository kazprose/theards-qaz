# Threads посты мен тредін жазу

## Қашан қолданылады

- «Threads-ке пост жаз», «қазақша пост керек»
- Жазбаң, идеяң бар, оны постқа айналдыру керек
- Ұзын мәтінді тредке бөлу керек

## Алдымен: профильді оқы

```python
import sys; sys.path.insert(0, ".")
from lib import profil_oqy
p = profil_oqy()   # None болса — профиль әлі жоқ
```

Профиль бар болса, аудиторияны, регистрді және бағаналарды содан ал — қайта сұрама.
Жоқ болса, `threads-profil` шеберлігін бір рет орындауды ұсын: бір минут кетеді,
ал әр посттағы қайталанатын сұрақтан құтыласың.

## Процесс

### 1-қадам. Үш нәрсені анықта

Пайдаланушы айтпаса, **сұра**. Бұл үшеуінсіз жазба:

| Не | Неге керек |
|---|---|
| **Мақсат** | жауап па, репост па, лайк па, дәйексөз бе — формула соған тәуелді |
| **Аудитория** | IT/стартап па, жалпы ма, ресми ме — регистр соған тәуелді |
| **Нақты факт** | сан, оқиға, өз тәжірибең — постың арқауы |

Нақты факт болмаса, пост жалпылама шығады. Пайдаланушыда факт жоқ болса,
соны айт та, «жалпылама пост жазуға болады, бірақ ол жауап әкелмейді» деп
ескерт.

### 2-қадам. Контейнерді таңда

| Идея қандай | Контейнер |
|---|---|
| Бір ой, бір сан, бір сәт | жеке пост |
| Бір постқа сыятын тізім | жеке пост (Q5) |
| Әр тармағы түсіндіруді керек ететін тізім | тред (Q10) |
| Басы-соңы бар оқиға | тред (Q11) |
| Қайталауға болатын процесс | тред (Q12) |

Бір жолдық ойды тредке созба — толтырма болып көрінеді.

### 3-қадам. Формуланы таңда

[`../../references/hook-formulasy.md`](../../references/hook-formulasy.md)
ішінен мақсатқа сай формуланы ал.

| Мақсат | Формулалар |
|---|---|
| Жауап | Q3, Q7, Q9, Q13 |
| Репост | Q1, Q2, Q5, Q10, Q12 |
| Лайк | Q6, Q8, Q11 |
| Дәйексөз | Q4, Q8, Q11 |

Q7 (тілдік байқау), Q8 (аударылмайтын ұғым), Q9 (екі тілдің арасы) —
қазақ контентіне ғана тән. Тақырып сай келсе, оларға артықшылық бер:
басқа тілде баламасы жоқ, сондықтан лентада бөлекше көрінеді.

### 4-қадам. Жаз

- Бірінші сөйлем 6-10 сөз. Қазақ тілі SOV, ұзын сөйлемде мағына кесіндіден
  тыс қалады.
- Бір постта бір ой.
- Нақты сан жалпы сын есімнен күшті.
- Дауыс ережелері:
  [`../../references/dauys-erejeleri.md`](../../references/dauys-erejeleri.md).

Тред болса, посттарды `---` арқылы өзің бөл. Threads «(1/5)» деп нөмірлемейді,
керек болса нөмірді мәтінге өзің жаз.

### 5-қадам. Тексер

Драфтты көрсетпес бұрын **міндетті түрде** іске қос:

```bash
python3 -m lib.audit "драфт мәтіні"
```

немесе Python арқылы:

```python
import sys; sys.path.insert(0, ".")
from lib import tolyq
print(tolyq(draft))
```

Шығатын қате түрлері:

- **Гомоглиф** — түзет, талқыламай. `lib.gomoglif_tuzetu()` бар.
- **Көлем** — 500-ден асса қысқарт немесе тредке бөл.
- **Хэштег** — біреуден артық болса, ең дәлін қалдыр.
- **Калька/кеңсе тілі** — әр табылымды контекске қарап шеш. Бәрін соқыр
  түзетпе: кейбірі заңды.

Түзеткеннен кейін қайта тексер.

### 6-қадам. Мақұлдау

```python
from lib import kartochka
print(kartochka(turi="post", mati=draft, hook_kody="Q3"))
```

Карточканы көрсет те, **тоқта**. Пайдаланушы «иә» немесе «қой» дегенше
ештеңе жариялама. Бұл ережеден ешқандай жағдайда шықпа.

### 6.5-қадам. Күтілетін нәтижені көрсет (журналда дерек болса)

```python
from lib import bolzham, tauekel
b = bolzham("Q3")                     # None болса — дерек жоқ, тыныш өт
belgiler, izah = tauekel(draft)
```

`bolzham` диапазонын **өткен нәтиже** ретінде айт, уәде ретінде емес.
`tauekel` белгісі шықса, оны түсіндірме жолымен бірге бер — ол
корреляция екенін оқырман білуі керек.

Дерек жеткіліксіз болса, екеуі де үнсіз қалады. Оны мәселе етпе.

### 7-қадам. Жариялау

Мақұлдағаннан кейін ғана:

```python
from lib import jariyala
natije = jariyala("post", mati=draft)
```

Әдепкі күйде бұл көшіріп-қоюға дайын блок қайтарады (ешқандай кілт керек
емес). `THREADS_TOKEN` бапталса — ресми API арқылы, `THREADS_POSTER`
қойылса — сол команда арқылы жарияланады.

#### Автоматты режим

`THREADS_AVTO=1` қойылған болса, мақұлдау қадамын аттап өтуге болады —
бірақ тек тексеруден ТОЛЫҚ өткен драфтты:

```python
from lib import avto_jariyala, tolyq
esep = tolyq(draft)
natije = avto_jariyala("post", draft, esep)
```

- `natije["avto"] is True` → жарияланды
- `natije["avto"] is False` → тоқтады, `natije["sebep"]` себебін айтады,
  ал `natije["habar"]` қолмен қоюға дайын блок береді

Бір ғана қате шықса, драфт **ешқайда жіберілмейді**. Автоматтандырудың
мәні — әр посттың басында отырмау, ал бұзық посттың автоматты шығуы сол
мәнді жоққа шығарар еді.

Автоматты режим қосылмаған болса, әрқашан 6-қадамдағы мақұлдау
карточкасын көрсет те, тоқта.

### 8-қадам. Журналға жазып қой

Жарияланғаннан кейін постты формуласымен бірге ұсын:

```python
from lib import jurnal_jaz, belgiler_al
from lib.jurnal import Jazba
jurnal_jaz(Jazba(kuni="2026-09-08", formula="Q3", maqsat="jauap",
                 tanba=len(draft), mati_bas=draft[:80],
                 url=natije.get("post_url", ""),   # МІНДЕТТІ, төменде қара
                 belgiler=belgiler_al(draft)))
```

**`url` жазылуы міндетті.** Онсыз `python3 -m lib.threads_api janart`
командасы бұл жазбаны Threads-тегі постпен байланыстыра алмайды да,
статистикасы автоматты тартылмайды. API арқылы жарияласаң, сілтеме
нәтижеде болады; қолмен қойсаң, пайдаланушыдан сұра.

`belgiler_al(draft)` — `tauekel()` кейін салыстыратын құрылымдық
белгілер. Оны жазбасаң, тәуекел талдауы жұмыс істемейді.

Бұл — бір жолдық қадам, бірақ бандлдың өзін-өзі түзететін жері: бірнеше
аптадан кейін `threads-natije` қай формула шынымен жүретінін көрсетеді.
Формуласыз жазылған пост кейін ешнәрсе үйретпейді.

## Шығару пішімі

Драфтты әрқашан мына ретпен көрсет:

1. Қай формула таңдалғаны және **неге** (бір жол)
2. Драфттың өзі, таңба санымен
3. Тексеру нәтижесі (қате болса — не түзетілгені)
4. Мақұлдау сұрағы
5. Мақұлданғаннан кейін — журналға жазу командасы

Формуланы неге таңдағаныңды түсіндіру маңызды: пайдаланушы келесі жолы
өзі таңдай алады.

## Не істемейміз

- Пайдаланушының атынан факт ойлап шығармаймыз. Сан керек болса — сұраймыз.
- Мақұлдаусыз жарияламаймыз.
- «Түсініктемеге жаз!» деп шақырмаймыз — Threads мұны төмендетеді.
- Постқа екі хэштег қоймаймыз.
