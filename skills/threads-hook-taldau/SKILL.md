# Hook талдау

Жұмыс істеген постты бөлшектеп, қайталауға болатын үлгіге айналдырады.

## Кіріс

Пайдаланушы не береді:

- Постың **мәтіні** (ең қолайлысы), немесе
- Постың **сілтемесі** — оны `lib.url_talda()` арқылы талда.

**Маңызды:** бұл бандлда Threads-тен мәтінді автоматты тартатын құрал жоқ.
Сілтеме берілсе, мәтінді сұра. Постың мазмұнын өзің ойлап шығарма — талдау
жалған болады.

```python
import sys; sys.path.insert(0, ".")
from lib import url_talda
print(url_talda("https://www.threads.com/@handle/post/KOD"))
```

## Талдау реті

### 1. Формуланы тап

[`../../references/hook-formulasy.md`](../../references/hook-formulasy.md)
ішіндегі 13 формуламен салыстыр. Дәл сәйкес келмесе, ең жақынын ал да,
айырмашылығын жаз. Күштеп сыйғызба — жаңа құрылым да болуы мүмкін.

### 2. Бірінші жолды бөлек қара

Threads лентада постты ~100-140 таңбадан кейін кеседі. Сондықтан бөлек
жауап бер:

- Кесіндіге дейін не көрінеді?
- Сол бөлігі өз бетінше тұрып, ойды жеткізе ме?
- Қазақ тілі SOV — етістік кесіндіден тыс қалып қойған жоқ па?

### 3. Мақсатын анықта

Пост қай сигналға құрылған: жауап, репост, лайк, әлде дәйексөз? Пост
құрылымы мен нақты сигнал сәйкес келмеуі мүмкін — соны да айт.

### 4. Тілдік жағын қара

Қазақша посттарда бұл жиі шешуші:

- Регистр: «сен» бе, «сіз» бе? Аудиториясы кім?
- Кодты ауыстыру деңгейі: неше кірме термин?
- Кеңсе тілі бар ма? (`python3 -m lib.kalka "мәтін"`)
- Тілдік байқау (Q7) немесе екі тілдің арасы (Q9) тақырыбы ма?

### 5. Не КӨШІРІЛМЕЙТІНІН айт

Ең пайдалы бөлігі. Кейбір пост құрылымымен емес, басқа нәрсемен жүреді:

- автордың аудиториясы үлкен,
- оқиға автордың өзінікі, қайталанбайды,
- сол кездегі жаңалыққа байланған,
- автордың бұрыннан қалыптасқан беделі бар.

Осыны ашық айт. Әйтпесе пайдаланушы құрылымды көшіріп, нәтиже болмағанда
себебін түсінбейді.

## Шығару пішімі

```
## Формула
{Код} — {аты}. {Неге солай шештім, бір-екі жол}.

## Қаңқасы
{постың құрылымы жол-жолымен}

## Бірінші жол
Кесіндіге дейін: «{...}»
{жеке тұрып жұмыс істей ме, неге}

## Мақсаты
{жауап / репост / лайк / дәйексөз} — {неге}

## Тіл
Регистр: {сен/сіз}, кірме термин: {N}, кеңсе тілі: {бар/жоқ}

## Бос үлгі
{толтыруға дайын шаблон}

## Не көшірілмейді
{құрылымнан тыс факторлар}
```

## Не істемейміз

- Постың мәтіні берілмесе, оны ойдан құрастырмаймыз.
- «Бұл пост X лайк жинады» деп сан ойлап шығармаймыз.
- Жалғыз посттан жалпы заңдылық шығармаймыз. Бір пост — бір бақылау.
