# Жобаны қалай дамыту керек

Маркетинг тұрғысынан жазылған ұсыныс. Қыркүйек 2026.

---

## 1. Ащы шындықтан бастайық

Жоба сапалы жасалған, бірақ **қате нарыққа бағытталған**.

Аудиторияны есептеп көрейік:

```
Threads қолданушылары
  ∩ қазақша жазатындар
    ∩ Claude Code / Codex қолданатындар
      ∩ контент маркетингпен айналысатындар
```

Әр қиылыс аудиторияны бірнеше есе қысқартады. Соңғы сан — жүздеген адам,
ең жақсы жағдайда мыңға жетер-жетпес. Бұл — жобаның сапасына емес,
**позициясына** қатысты мәселе.

Мұны айтып отырғаным «жобаң нашар» дегенім емес. Керісінше: ең құнды
бөлігі Threads-те емес, ал маркетинг соны көрмей отыр.

## 2. Нақты актив қайда

Репозиторийді екіге бөліп қара:

| Қабат | Көлемі | Бәсекелестігі |
|---|---|---|
| Threads шеберліктері | ~2 500 жол markdown | Ондаған ұқсас бандл бар |
| **Қазақ тілі қабаты** | **~900 жол Python** | **Іс жүзінде жоқ** |

Тіл қабаты — `emle.py`, `kalka.py`, `undestik.py`, `translit.py`,
`profil.py`. Оның ерекшелігі:

- **Жұмыс істейді** — 79 тест, жалған белгі бермейді.
- **Тәуелділіксіз** — `pip install` керек емес, кез келген жерде жүреді.
- **MIT** — ал бар баламалардың бәрі GPL.
- **Тірі** — бәсекелестері 2014-2018 жылдардағы академиялық жобалар,
  көбі тоқтап қалған.

Threads — бұл қабаттың **демосы**, өнімнің өзі емес.

## 3. Сына: гомоглиф мәселесі

Маркетингте ең күшті хабар — көрінбейтін, бірақ дәлелденетін мәселе.
Гомоглиф дәл сондай:

- **Көрінбейді.** `бiр` мен `бір` экранда бірдей.
- **Тексеріледі.** Мәтінді қоясың — қате шығады, дауласуға болмайды.
- **Зияны нақты.** Іздеу таппайды, хэштег өледі, сұрыптау бұзылады.
- **Бәрінде бар.** Пернетақта ауысқанда байқаусыз кетеді.

### Дәлел (осы жобаның кодымен табылған)

`hunspell-kk` — LibreOffice пен OpenOffice қолданатын **ресми қазақ
орфографиялық сөздігі**, 54 063 сөз. Сканерлеу нәтижесі:

```
тексерілді: 54 063 сөз
гомоглиф:   16 сөз
```

Табылғандары — қазақтың белгілі жазушыларының есімдері:

| Сөздіктегі жазылуы | Бөгде таңба | Дұрысы |
|---|---|---|
| `Бейiмбет` | `i` U+0069 LATIN SMALL I | Бейімбет |
| `Сейiт` | `i` U+0069 | Сейіт |
| `Iсмет` | `I` U+0049 LATIN CAPITAL I | Ісмет |
| `Aманжол` | `A` U+0041 LATIN CAPITAL A | Аманжол |
| `Мусiреп`, `Нурпейiс`, `Суйінбай` … | `i` | … |

**Ең маңыздысы:** дұрыс жазылған нұсқасы сөздікте **мүлдем жоқ**.

Салдары: сен «Бейімбет» деп ДҰРЫС жазасың — емле тексергіш оны **қате**
деп белгілейді. Ал `Бейiмбет` деп бұзып жазсаң — қабылдайды.

> Қазақтың ресми орфографиялық сөздігі қате жазуды үйретіп тұр.

Бұл — жарнама емес, тексерілетін факт. Оны табу бірнеше секунд алды.

## 4. Үш қадам

### Қадам 1. Тіл ядросын бөліп шығару

`lib/` ішіндегі тіл модульдерін жеке репозиторийге шығар: **`qaz-lint`**
(немесе `qazaq-tili`). MIT, тәуелділіксіз, CLI + кітапхана.
`threads-qazaqsha` соны пайдаланушыға айналады.

Не өзгереді: аудитория Threads маркетологтарынан **кез келген қазақ
мәтінімен жұмыс істейтін адамға** ауысады — әзірлеуші, локализация
маманы, редактор, баспа, мемлекеттік мекеме.

Бұл — 10-100 есе кең нарық, әрі код дайын тұр.

### Қадам 2. Сынаны жариялау (ең арзан әрі ең күшті қадам)

Реті маңызды. **Алдымен түзет, содан кейін айт.**

1. `hunspell-kk` мен `myspell-kk` репозиторийлеріне 16 сөзді түзететін
   PR жібер. Бұл — беделдің негізі: сынап қана қоймай, түзеттің.
2. Содан кейін жаз: «Қазақтың ресми орфографиялық сөздігінде 16 есім
   латын әрпімен жазылған, ал дұрыс нұсқасы сөздікте жоқ».
3. Сканерді ашық қой: кез келген адам өз мәтінін тексере алсын.

Мұндай хабар өзі тарайды. Жұлдыз сұраудың қажеті болмайды.

**Ескерту:** 16 сөз — бір сөздіктегі нәтиже. Оны «қазақ мәтінінің
X пайызында гомоглиф бар» деп жалпылама айтуға болмайды. Ондай сан
керек болса, алдымен өлшеу керек.

### Қадам 3. Дистрибуцияны кеңейту

Қазіргі жалғыз арна — Claude плагині. Ал қазақша контент жазатын
адамдардың басым бөлігі Claude Code-ты **қолданбайды**.

Бір кодтан бес арна шығады:

| Арна | Кімге жетеді | Күрделілігі |
|---|---|---|
| **Веб-демо** (мәтінді қой → қатені көр) | бәріне, орнатусыз | төмен |
| **GitHub Action** (CI-да мәтінді тексеру) | командаларға | төмен |
| `pre-commit` hook | әзірлеушілерге | төмен |
| PyPI пакеті | Python экожүйесіне | төмен |
| VS Code кеңейтімі | редакторда жазатындарға | орташа |

Веб-демо — ең маңыздысы. Орнатуы жоқ, тіркелуі жоқ, бір экран.
Сына сол жерде жұмыс істейді.

## 5. Кімге және не сатуға болады

| Сегмент | Мөлшері | Ақшасы | Не керек |
|---|---|---|---|
| Қазақ әзірлеушілері | орташа | жоқ | тегін құрал, дистрибуция көзі |
| SMM, контент | шағын | аз | веб-демо, Threads бандлы |
| **Компаниялар** | шағын | **бар** | CI-ға кіретін мәтін сапасы |
| Мемлекет, білім | үлкен | бар, бірақ баяу | ұзақ сатылым |

**Ақша үшінші жолда.** Қазақстанда компаниялардың қазақ тілінде контент
шығару міндеті бар, ал сапасы төмен: аударма мәжбүрліктен жасалады,
сондықтан калька мен гомоглифке толы.

Ұсыныс солай тұжырымдалады: *«Қазақша мәтініңіз жарияланғанға дейін
тексеріледі — гомоглиф, калька, регистр»*. Бұл — жаңа ұғым емес, бар
процеске (CI) кіретін нәрсе.

Бірақ: алдымен тегін қабат тарауы керек. Компания сатып алмас бұрын
құралды өз әзірлеушісінен естуі керек.

## 6. Корпус — ұзақ мерзімді моат

`lib/jurnal.py` қазір жеке пайдаланушыға арналған. Бірақ ол — потенциалды
**дерек жинау механизмі**.

Егер 20-30 адам өз нәтижесін ерікті түрде (анонимді) бөліссе, қазақ
тіліндегі әлеуметтік контенттің **алғашқы корпусы** пайда болады. Ол
болса, `hook-formulasy.md` болжам болудан қалады.

Мұны асыра бағаламау керек: 20 тұрақты қолданушы жинау — оңай емес, әрі
дербес дерекпен жұмыс істеудің өз талаптары бар. Бұл — үшінші жылдың
мақсаты, бірінші айдың емес.

## 7. Не істемеу керек

- **Instagram, TikTok, LinkedIn бандлдарын қоспау.** Әлсіз базада
  көлденең кеңею әлсіздікті көбейтеді. Түпнұсқа `sergebulaev` жеті
  платформаға тараған, бірақ әрқайсысы жұқа.
- **«Репоны жұлдызшала» деген промпт қоспау.** Түпнұсқада бар. Бұл —
  модельдің аузымен жасалған өтініш, беделге зиян.
- **Шеберліктерді ағылшыншаға аудармау.** Қазақтығы — әлсіздік емес,
  моат. Ағылшынша нұсқасында бәсекелестік мыңға шығады.
- **SaaS-ты ерте бастамау.** Сына дәлелденбей тұрып, инфрақұрылым салу —
  ең жиі кездесетін қате.
- **`theards` деген атауды қалдырмау.** Бұл — қате жазылған `threads`.
  Іздеуден табылмайды, сенім тудырмайды. Атын ауыстыру керек.

## 8. Нені өлшеу керек

Жұлдыз — бос көрсеткіш (`references/olshem.md` ішіндегі ереже өзімізге де
қатысты).

| Нақты көрсеткіш | Неге маңызды |
|---|---|
| Демо емес, **нақты мәтінге** жүргізілген тексеру саны | шын қолданыс |
| **Басқа репозиторийлерде** түзетілген қате саны | құндылықтың дәлелі |
| Ядроны пайдаланатын жобалар | дистрибуция |
| Журналға қосылған жазба | корпус бағыты |

Екінші жол — ең күштісі. «Біздің құрал басқа жобалардағы N қатені
түзеді» деген сөйлемді жұлдыз саны ешқашан бере алмайды.

## 9. Не білмеймін

Адал болу үшін:

- **Қазақ Threads аудиториясының нақты мөлшерін білмеймін.** Жоғарыдағы
  есеп — логика, өлшем емес.
- **Компаниялар төлей ме — тексерілмеген.** Гипотеза. Тексерудің жолы:
  5-10 компанияға хабарласып сұрау, өнім салмай тұрып.
- **Hook формулалары жұмыс істей ме — әлі белгісіз.** Бұл жоба басынан
  бері айтылып келеді, әлі шешілмеген.
- **16 гомоглиф — бір сөздіктегі нәтиже.** Кең тарағанын дәлелдеу үшін
  әлдеқайда көп мәтін сканерлеу керек.

## 10. Келесі жеті күн

Ретімен, ең арзанынан:

1. Репозиторий атын түзету (`theards` → мағыналы атау).
2. `hunspell-kk`-ге 16 сөзді түзететін PR.
3. Тіл ядросын жеке пакетке бөлу.
4. Веб-демо (бір бет, backend жоқ).
5. GitHub Action.

Бірінші екеуі — бір сағаттық жұмыс, ал ең үлкен әсер соларда.
