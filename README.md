## Неге керек

Қазақша пост жазғанда AI-дың төрт нәрсесі тұрақты түрде бұзылады:

| Мәселе | Мысал | Салдары |
|---|---|---|
| **Гомоглиф** | `бiр` (латын i) vs `бір` (кирилл і) | іздеу таппайды, хэштег өледі |
| **Үндестік** | `дедлайнге` (дұрысы `дедлайнға`) | кірме сөзге қосымша қате жалғанады |
| **Регистр** | бір постта «сен» де, «сіз» де | ең байқалатын жасандылық |
| **Орысша калька** | «мақсатымыз болып табылады» | пост хабарламаға айналады |
| **Кодты ауыстыру** | «мерзімге үлгермедік» | жасанды естіледі |
| **Аударма синтаксисі** | ағылшынша SVO ретімен жазу | AI жазғаны бірден көрінеді |

Бірінші мәселе — ең жаманы, өйткені **көзге көрінбейді**. Латын `i` мен
кирилл `і` экранда бірдей. Постың дұрыс жазылғанына сенімдісің, ал іздеу оны
таппайды.

```
$ python3 -m lib.emle "Бiз бүгін жаңа фичаны шығардық. #қазақстан #стартап"

Таңба: 60/500 | сөз: 8 | хэштег: 2 | қазақ әрпінің үлесі: 15.1%

[ҚАТЕ] гомоглиф: «Бiз» сөзінде латын әрпі бар: «i» → «і». Дұрысы: «Біз».
       Көзге бірдей көрінеді, бірақ іздеу таппайды.
[ҚАТЕ] хэштег: 2 хэштег. Threads біреуін ғана қабылдайды.
```

Орнатқаннан кейін Claude-қа жай сұра. Керекті шеберлік өзі қосылады.

> «Threads-ке қазақша пост жаз: интерфейсті қазақшаладық, үш аптада
> қолданушының 41%-ы қазақшаға ауысты»

> «Мына мәтінді тазала, кеңсе тілі көп сияқты: …»

> «Жіберер алдында тексер: …»

> «Мына постың hook-ы қандай? Мәтінін қоямын: …»

> «Аптасына 5 пост жоспарын құр. Мен қазақша оқу қосымшасын жасаймын,
> аудиториям — мұғалімдер.»

> «Постымның нәтижесін жазып қой: Q3 формуласы, 1200 көрсетілім, 14 жауап»

Әр шеберлік драфтты көрсетеді де **тоқтайды**. Сен «иә» дегенше ештеңе

## Қазақ контентіне тән үш hook формуласы

13 формуланың үшеуі басқа тілде жоқ:

- **Q7 — тілдік байқау.** Бір сөздің, аударманың қызық жері. Қазақ тіліндегі
  желіде ең тұрақты жұмыс істейтін тақырып: тіл — ортақ меншік, әркім өз
  нұсқасын ұсынады, ал әр ұсыныс — жауап.
- **Q8 — аударылмайтын ұғым.** Қазақшасы бар, басқа тілде жоқ ұғым.
  Дәйексөзге жақсы кетеді.
- **Q9 — екі тілдің арасы.** Қазақша мен орысша/ағылшынша арасында жүрген
  адамның нақты қиындығы. Аудиторияның басым бөлігі дәл сол жағдайда.

Толығы: [`references/hook-formulasy.md`](references/hook-formulasy.md).

## Дауыс профилі

Ең бірінші жасайтын нәрсе. Бір рет толтырасың — қалған сегіз шеберлік
аудиторияны, регистрді, бағаналарды содан оқиды да, әр жолы қайта сұрамайды.

```bash
python3 -m lib.profil ulgi > .threads-profil.md   # үлгіні жазады
python3 -m lib.profil                             # не толтырылғанын көрсетеді
```

Немесе Claude-қа «дауыс профилін құрайық» деп айт — сұхбат арқылы толтырады.

Ең құндысы: профильдің екі бөлігі **машинамен тексеріледі**.

| Тексеру | Деңгейі | Профиль керек пе |
|---|---|---|
| Бір постта «сен» мен «сіз» араласқаны | қате | жоқ |
| Драфттың регистрі профильге қайшы | ескерту | иә |
| Тыйым салынған сөз кездескені | ескерту | иә |

Регистрдің араласуы профильсіз де ұсталады — бір постта екеуін қатар
қолдану оқырманға бірден байқалады.

Детектор «сенім», «сенбі», «сенімді» тәрізді сөздерді «сен» деп
санамайды, «мәнсіз», «ақшасыз» дегенді «сіз» деп санамайды. Тек сенімді
белгілер қолданылады: азырақ ұстау — жалған белгі беруден жақсы.

Профиль — жай мәтін файл, git-ке сыяды. Жеке дерек болса,
`.gitignore` ішіне қосасың.

## Болжамды бақылауға айналдыру

Бандлдағы hook формулалары — болжам. Оны шындыққа айналдыратын жалғыз жол —
өлшеу, ал ол үшін `threads-natije` шеберлігі бар.

```bash
# Пост жарияланғанда — формуласымен бірге жазып қой
python3 -m lib.jurnal qos Q3 jauap "постың алғашқы сөздері"

# Сандар: ресми API арқылы автоматты тартылады
python3 -m lib.threads_api janart

# Қорытынды
python3 -m lib.jurnal esep
```

```
## Формула бойынша (жауап үлесі бойынша реттелген)

  Q7: 6/6 өлшенген | әрекет 6.50% | жауап 3.12%
  Q3: 7/7 өлшенген | әрекет 6.00% | жауап 2.11%
  Q2: 5/5 өлшенген | әрекет 5.98% | жауап 0.38%  ⚠ үлгі аз
```

Үш ережесі:

- **Сан не ресми API-дан, не Insights экранынан келеді.** Бандл ешқандай
  санды ойдан шығармайды.
- **Медиана, орташа емес.** Бір вирусты пост орташаны бұзады, ал шағын
  аудиторияда ондай пост жиі кездеседі.
- **5 өлшенген посттан аз болса, қорытынды жасалмайды.**

Қазақша аудитория шағын болғандықтан, статистикалық маңыздылық шықпайды.
Сондықтан ереже басқа: ~20%-дан асқан әрі 3-5 рет қайталанған айырмаға ғана
сену керек. Толығырақ: [`references/olshem.md`](references/olshem.md).

## Автоматтандыру

Екеуі де ерікті. Әдепкі күйде ештеңе автоматты жүрмейді.

### Статистиканы автоматты тарту

`THREADS_TOKEN` бапталса, сандарды қолмен теру керек емес — Threads-тің
ресми API-ы арқылы тартылады. Журнал өзі толады.

Баптауы: `.env.example` ішінде. Meta-да қосымша тіркеу керек, бір-екі
сағаттық жұмыс. Тек **өз аккаунтыңа** жүреді.

### Мақұлдаусыз жариялау

`THREADS_AVTO=1` қойсаң, драфт өзі жарияланады — **бірақ тек тексеруден
толық өткені**.

```
тексеру таза  → жарияланады
бір қате бар  → тоқтайды, себебін айтады, қолмен қоюға блок береді
```

Бұзық драфт бас тартылғанда **ешқандай backend-ке жіберілмейді**.
Автоматтандырудың мәні — әр посттың басында отырмау, ал бұзық посттың
автоматты шығуы сол мәнді жоққа шығарар еді.

Жауап пен дәйексөз бұл режимде де ешқашан автоматты жарияланбайды: олар
бөтен постқа байланады, ал қате нысанаға түсу қаупі бар.

### Күтілетін нәтиже мен тәуекел

Журналда дерек жиналған соң:

```python
from lib import bolzham, tauekel
print(bolzham("Q3"))
# Q3 форматындағы 12 постың: жауап үлесі 1.4%–3.1%, медианасы 2.1%.
# Бұл — өткен нәтиже, кепілдік емес.

belgiler, izah = tauekel(draft)
# ұзындығы: бұл драфтта 300. Нашар жүргендерде медианасы 290, жақсыларда 95.
# Салыстыру негізі: 14 өлшенген пост. Бұл — корреляция, себеп емес.
```

Екеуі де **өткен деректі** көрсетеді, болашақты болжамайды. Дерек
жеткіліксіз болса (5 посттан аз), екеуі де үнсіз қалады — ойдан
сан шығарылмайды.

## Дәлел туралы ашық сөз

Қазақ тіліндегі Threads посттарының өлшенген корпусы **жоқ**. Сондықтан бұл
репозиторий «қазақша постың орташа қамтуы мынадай» деген сан келтірмейді.

Әр ұсыныстың көзі белгіленген:

- `[платформа]` — Threads-тің қатты шектеуі (500 таңба, бір хэштег). Даусыз.
- `[редактура]` — қазақ тіліндегі редакторлық тәжірибе. Тұрақты, бірақ
  талғам мәселесі бар.
- `[болжам]` — тексеруге тұрарлық гипотеза.

Бұл шеберліктер мәтіннің AI детекторынан өтуіне **кепілдік бермейді** және
оны мақсат етпейді. Мақсат басқа: тірі адам оқығанда бөгде естілмеу.

## Автопост

Әдепкі күйде драфт көшіріп-қоюға дайын блок болып қайтады. Кілт те, тіркелу
де, ақылы қызмет те керек емес.

Автопост қаласаң, `THREADS_POSTER` айнымалысына өз командаңды жаз:

```bash
THREADS_POSTER="python3 менің_постерім.py"
```

Драфт stdin арқылы JSON болып беріледі:

```json
{"turi": "post", "mati": "…", "nysana_url": "…"}
```

Постерді Threads Graph API-мен де, кез келген жариялау сервисімен де жаза
аласың. **Бандл ешқандай нақты қызметке байланбаған** — бұл әдейі: жариялау
жолын сен таңдайсың.

Жауап пен дәйексөз әрқашан қолмен қойылады. Олар басқа адамның постына
байланатын бөлек пост, ал автоматты жариялау қате нысанаға түсу қаупін
тудырады.

## Кітапхана

`lib/` жеке де қолданылады, шеберліксіз:

```python
import sys; sys.path.insert(0, "threads-qaz")
from lib import tolyq, gomoglif_tuzetu, undestik_tekseru, hashtag_nusqalary, latynga

print(tolyq("постың мәтіні"))           # емле + тазалық + үндестік + профиль
print(gomoglif_tuzetu("Бiз"))           # → Біз      (латын i → кирилл і)
print(gomoglif_tuzetu("Clаudе"))        # → Claude   (кирилл а,е → латын a,e)
print(undestik_tekseru("дедлайнге"))    # → дедлайнға
print(hashtag_nusqalary("қазақ тілі"))  # кирилл + латын нұсқасы
print(latynga("тіл"))                   # tıl — і → ı (нүктесіз), и → i (нүктелі)
```

Командалық жолдан:

```bash
python3 -m lib.emle "мәтін"      # гомоглиф, әліпби, Threads шектеулері
python3 -m lib.kalka "мәтін"     # калька, кеңсе тілі, құрылым
python3 -m lib.undestik "мәтін"  # дауысты үндестігі
python3 -m lib.translit "сөз"    # транслитерация, хэштег
python3 -m lib.audit "мәтін"     # бәрі бірге, шығу коды 0/1
python3 -m lib.jurnal esep       # қай формула жүріп тұр
python3 -m lib.profil            # дауыс профилі
python3 -m lib.threads_api janart # статистиканы API-дан тарту
```

Төртеуі де CI-да жүреді. Қосқың келсе —
[`CLAUDE.md`](CLAUDE.md) ішінде ережелер жазылған.

Әсіресе пайдалы үлес: `lib/kalka.py` ішіндегі `SOZDIK` тізіміне жаңа калька
қосу. Әр жазбаға орысша түпнұсқасын және нақты баламасын жаз.

## Қауіпсіздік

Жоба екі нәзік нәрсеге тиеді: Threads API токеніне және сенің атыңнан
жария контент шығаруға. Толық ережелер — [`SECURITY.md`](SECURITY.md).

Ең қысқасы:

- **Ең аз рұқсат.** Автопост керек болмаса, `threads_content_publish`
  рұқсатын мүлдем сұрама. Сонда токен ұрланса да, онымен ештеңе
  жарияланбайды.
- **Токенді чатқа жазба.** Код оны айнымалыдан не файлдан өзі оқиды.
- **Токен ашылса — жарамсыз ет.** Файлды өшіру жеткіліксіз, ол git
  тарихында қалады.
- **Телеметрия жоқ.** Журнал мен профиль сенің машинаңда қалады,
  ешқайда жіберілмейді.
- **Бөтен посттың мәтіні — дерек, нұсқау емес.** Талдауға берілген
  мәтінде жасырын нұсқау болуы мүмкін.

Осалдық тапсаң, ашық issue ашпа: репозиторийдің **Security** қойындысы →
**Report a vulnerability**.
