# Әліпби, емле және Threads-тегі техникалық шектеулер

## 1. Гомоглиф — №1 үнсіз қате

Латын мен кириллдің кейбір әріптері экранда **бірдей** көрінеді, бірақ
Unicode-та бөлек таңбалар.

| Латын | Кирилл | Қауіп |
|---|---|---|
| `i` | `і` | ең жиі. «бiр» ↔ «бір» |
| `a` | `а` | |
| `e` | `е` | |
| `o` | `о` | |
| `p` | `р` | |
| `c` | `с` | |
| `x` | `х` | |
| `y` | `у` | |
| `A B C E H K M O P T X Y` | `А В С Е Н К М О Р Т Х У` | бас әріптер |

Салдары:

- Threads пен Instagram іздеуі сөзді таппайды.
- Хэштег басқа хэштегке айналады, ешкім көрмейді.
- Мәтінді көшірген адамның жазбасы да бұзылады.

Себебі: пернетақта қазақша/ағылшынша ауысқанда байқалмай қалады. Әсіресе
`i` әрпі — қазақ пернетақтасында `і` мен ағылшын `i` бір орында.

**Тексеру:** `python3 -m lib.emle "мәтін"`
**Түзету:** `lib.gomoglif_tuzetu(mati)` — тек аралас сөзді түзетеді, `Claude`,
`AI` сияқты таза латын сөздеріне тимейді.

## 2. Қазаққа тән әріптер

`ә ғ қ ң ө ұ ү һ і` — бұл тоғыз әріп мәтіннің қазақша екенін көрсетеді.
Қалыпты қазақ мәтінінде олардың үлесі барлық кирилл әрпінің **8-15%**-ын
құрайды.

3%-дан төмен болса, мәтін екеуінің бірі:

- орысшадан тікелей аударылған (сөздері қазақша, құрылымы орысша),
- кірме сөзге толы («менеджер», «процесс», «система» тізбегі).

`lib/emle.py` бұл үлесті есептеп, төмен болса ескертеді.

### Жиі шатасатын жұптар

| Жұп | Ереже |
|---|---|
| `қ` / `к` | қалың дауысты сөзде `қ`: **қ**ала, **қ**ыс. Жіңішкеде `к`: **к**ел, **к**іс |
| `ғ` / `г` | сол принцип: **ғ**ылым, **г**үл |
| `ұ` / `ү` | **ұ** қалың (**ұ**зақ), **ү** жіңішке (**ү**й) |
| `і` / `и` | `і` — қазақтың қысқа дауыстысы (**і**ш), `и` — кірме әріп (**и**дея) |
| `ә` / `а` | **ә**ке, **а**та — мағына өзгереді |
| `х` / `һ` | `һ` тек бірнеше сөзде: **һ**әм, қа**һ**арман, гау**һ**ар |

## 3. Тек кірме сөзде жүретін әріптер

`ё ъ ь э щ ц ч ф` — қазақтың төл сөздерінде кездеспейді. Мәтінде көп болса,
кірме сөздің қазақша баламасы бар ма деп тексер.

Бірақ бұл ереже емес, **сигнал**: «фотограф», «цифр» сияқты сөздердің
баламасы жоқ немесе жасанды.

## 4. Хэштег: кирилл ме, латын ба

Threads хэштегті таңбамен дәл салыстырады. `#қазақстан` мен `#qazaqstan` —
екі бөлек хэштег, аудиториясы да бөлек.

Постқа **бір ғана** хэштег сыятындықтан, таңдау нақты:

| Хэштег | Қашан |
|---|---|
| кирилл (`#қазақша`) | аудиторияң Қазақстанда, қазақша жазады |
| латын (`#qazaqsha`) | диаспора, халықаралық аудитория, IT ортасы |

`lib/translit.hashtag_nusqalary("сөз")` екі нұсқасын да қайтарады.

Транслитерация — QazLat 2021 (умлаут/бревис нұсқасы). Хэштегке диакритикасыз
ASCII нұсқасы қолданылады: `ä→a`, `ğ→g`, `ñ→n`, `ö→o`, `ş→s`, `ū/ü→u`.

## 5. Таңба шегі мен қазақ тілінің ұзындығы

Threads: **500 таңба** бір постта, мәтін тіркемесімен 10 000.

Қазақ тілі жалғамалы, сондықтан бір ой ағылшынға қарағанда **~20% көп таңба**
алады. Практикалық салдар:

- Ағылшынша 500 таңбаға сыятын ой қазақша 600-ге созылады.
- Шешім: сөзді қысқарту емес, **ойды азайту**. Бір постта бір ой.
- Кеңсе тіркестері таңбаны екі есе жейді: «жүзеге асыру» (14) vs «істеу» (6).
  Тіл тазалығы бұл жерде тікелей көлем үнемдейді.

`lib/emle.py` 460 таңбадан асқанда ескертеді — эмодзи мен сілтеме қосылса,
шекке жетіп қалатындықтан.

## 6. Тыныс белгісі

- **Сызықша (—)** бастауыш пен баяндауыштың арасында: «Тіл — құрал». Бұл
  норма, AI белгісі емес. Тығыздығы ғана маңызды: постқа біреу жеткілікті.
- **Дефис (-)** қосымша жалғағанда: `AI-ды`, `Threads-ке`.
- **Қос нүкте** тізім немесе түсіндірме алдында — Threads-те жақсы жұмыс
  істейді, өйткені оқырманды келесі жолға тартады.
- Леп белгісін шамала. Бір постта біреуден көп болса, айқай болып естіледі.

## 7. Тексеру реті

```bash
python3 -m lib.emle "постың мәтіні"
```

Шығатыны: гомоглиф, әліпби үлесі, таңба саны, хэштег саны, сілтеме орны,
эмодзи саны. Барлығы механикалық — стиль мен тонды модель өзі бағалайды.
