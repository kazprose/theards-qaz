# 13 hook формуласы — қазақша Threads

## Дәлел туралы ескерту

Қазақ тіліндегі Threads посттарының өлшенген корпусы жоқ. Төмендегі
формулалар екі негізден құралған:

1. **Threads механикасы** — платформа жауапты (reply) ең ауыр сигнал санайды,
   лента ұзын постты кеседі, сілтеме қамтуды төмендетеді. Бұл — платформаның
   өз құрылымы, тілге тәуелсіз.
2. **Қазақ тіліндегі әлеуметтік желі тәжірибесі** — қандай тақырып пікір
   тудыратыны, қай тон бөгде естілетіні.

Әрқайсысы — **тексеруге тұрарлық гипотеза**, өлшенген заңдылық емес. Q7-Q9
формулалары қазақ контентіне ғана тән, басқа тілде баламасы жоқ.

## Мақсат бойынша таңдау

Threads төрт сигналды бөлек өлшейді. Формуланы **алдымен мақсат бойынша**
таңда, тақырып бойынша емес.

| Мақсат | Не береді | Формулалар |
|---|---|---|
| **Жауап** | ең ауыр сигнал, лентада алға шығарады | Q3, Q7, Q9, Q13 |
| **Репост** | өз аудиторияңнан шығасың, «сақтау» орнына жүреді | Q1, Q2, Q5, Q10, Q12 |
| **Лайк** | ең жеңіл сигнал, әлеуметтік дәлел | Q6, Q8, Q11 |
| **Дәйексөз** | басқа адам өз пікірін қосып таратады | Q4, Q8, Q11 |

# Жеке пост формулалары (Q1-Q9)

## Q1 — Жұмсақ қарсы пікір
**Мақсат: репост**

Көпшілік ойлайтын нәрсеге қарсы шығасың, бірақ шақыру ретінде, ұрыс ретінде
емес. Threads-те X-тегі кекесін жүрмейді.

```
{Көпшілік осылай дейді}.
Мен басқаша көремін: {қарсы пікір}.
{Бір дәлел, нақты}.
```

> Қазақша контент аз деп жүрміз.
> Меніңше, аз емес — табылмайды.
> Іздеу қазақша хэштегті кирилл жазса ғана табады, ал көбі латынша қояды.

**Неге жүреді:** оқырман келіседі не келіспейді, екеуі де әрекет.
**Қателік:** айыптауға айналдырма. «Бәрі қате істеп жүр» — жабылу.

## Q2 — Нақты сан
**Мақсат: репост**

Бір ғана күтпеген сан бүкіл постты көтереді. Сан дөңгелек болмауы керек:
«2.4 есе» «екі есеге» қарағанда шынайы естіледі.

```
{Күтпеген сан}.
{Ол нені білдіреді}.
{Бір жол қорытынды}.
```

> Интерфейсті қазақшаладық. Үш аптада қолданушының 41%-ы қазақшаға ауысты.
> Біз 10% күтіп едік.
> Сұраныс бар екен, тек ешкім ұсынбаған.

**Қателік:** санды түсіндіріп жіберме. Сан өзі сөйлейді.

## Q3 — Ашық мойындау
**Мақсат: жауап**

Өз жұмысыңның нашар нәтижесін көрсетесің. Threads-те ең көп жауап осы
формулаға түседі, өйткені адамдар өз ұқсас тәжірибесін айтқысы келеді.

```
{Не істедім}.
{Не болмай қалды — нақты}.
{Әлі шешілмеген сұрақ}.
```

> Қазақша подкаст шығардық. Алты айда 300 тыңдаушы.
> Ағылшыншасы бір айда 4000 жинады.
> Аудитория жоқ па, әлде мен таба алмай жүрмін бе — түсінбей отырмын.

**Қателік:** соңында «бірақ бұл маған көп нәрсе үйретті» деп жаба салма.
Ашық сұрақ қалдыр — жауап сол сұраққа келеді.

## Q4 — Дәйексөзге қосымша
**Мақсат: дәйексөз**

Басқа адамның постын дәйексөзге алып, өз қабатыңды қосасың. Келіспеу емес,
кеңейту.

```
{Түпнұсқа постқа сілтеме — дәйексөз арқылы}
Осыған бір нәрсе қосамын: {сенің қабатың}.
{Неге маңызды}.
```

**Қателік:** түпнұсқаны қайталама. Қоспайтын болсаң, жай лайк бас.

## Q5 — Қысқа тізім
**Мақсат: репост**

Бір постқа сыятын тізім. Тредке айналдырма — тізім тұтас көрінгенде
сақталады.

```
{Тақырып}: {N} нәрсе.

1. {қысқа}
2. {қысқа}
3. {қысқа}

{Бір жол қорытынды немесе сұрақ}.
```

**Ереже:** 3-5 тармақ. Әр тармақ бір жол. Алтауы болса — тред.

## Q6 — Таныс сәт
**Мақсат: лайк**

Кіріспесіз, бірден нақты сәт. Оқырман «мен де солай» дейді.

```
{Нақты сәт, бірінші жақтан, кіріспесіз}.
{Бір жол — не сездің}.
```

> Әжем «мессенджерде жаз» дегенді «хат жаз» дейді.
> Мен әлі күнге түзетпеймін.

**Қателік:** жалпылама айтпа. «Бәрімізге таныс» деген тіркес постты өлтіреді.

## Q7 — Тілдік байқау
**Мақсат: жауап** · қазақ контентіне тән

Бір сөздің, тіркестің немесе аударманың қызық жері. Қазақ тіліндегі
әлеуметтік желіде бұл — ең тұрақты жұмыс істейтін тақырып, өйткені
әркімнің өз нұсқасы бар.

```
{Сөз/тіркес} туралы бір нәрсе байқадым.
{Байқаған нәрсең}.
{Ашық сұрақ: сендерде қалай?}
```

> «Дедлайн» сөзін қазақшалауға тырысып көрдім. «Мерзім» жеткізбейді екен —
> дедлайнда қорқыныш бар, мерзімде жоқ.
> Сендер қалай айтасыңдар?

**Неге жүреді:** тіл — ортақ меншік. Әркім өз нұсқасын ұсынады, ал әр
ұсыныс — жауап.
**Қателік:** сабақ бере бастама. Байқау болсын, лекция емес.

## Q8 — Аударылмайтын ұғым
**Мақсат: дәйексөз, лайк** · қазақ контентіне тән

Қазақша бар, басқа тілде жоқ ұғымды түсіндіресің. Мұндай пост дәйексөзге
жақсы кетеді, өйткені адам оны басқаға көрсеткісі келеді.

```
{Сөз} — {қысқа мағынасы}.
{Ағылшынша/орысша неге аударылмайтыны}.
{Бір қолданыс мысалы}.
```

**Қателік:** мақтауға айналдырма («біздің тіл бай») — ол постты насихатқа
айналдырады. Бір ғана нақты сөз, бір ғана нақты мысал.

## Q9 — Екі тілдің арасы
**Мақсат: жауап** · қазақ контентіне тән

Қазақша мен орысша/ағылшынша арасында жүрген адамның нақты қиындығы.
Аудиторияның басым бөлігі дәл сол жағдайда, сондықтан жауап көп келеді.

```
{Нақты жағдай: қай тілде не істедің}.
{Не ыңғайсыз болды}.
{Сұрақ}.
```

> Кездесуде қазақша сөйлеп, слайдты ағылшынша жасадым.
> Ортасында өзім шатасып қалдым — терминді аударуға тырысып.
> Сендер презентацияны қай тілде жасайсыңдар?

**Қателік:** кінәлі іздеме. Пост «кім жазалы» дегенге айналса, талқы емес,
ұрыс шығады.

# Тред формулалары (Q10-Q13)

Тредтегі әр пост тәулік квотасынан жеке есептеледі. Тред бірінші постпен
сатылады: адам оны ашпаса, қалғанын көрмейді.

## Q10 — Тізім-тред
**Мақсат: репост**

Бірінші постта уәде, әр келесі постта бір тармақ.

```
1-пост: {N} {нәрсе}, {уақыт/тәжірибе} ішінде жинаған.
---
2-пост: 1. {тармақ + түсіндірме}
---
3-пост: 2. {тармақ + түсіндірме}
...
Соңғы: {қорытынды немесе сұрақ}
```

**Ереже:** нөмірді өзің қой. Threads X сияқты «(1/5)» қоймайды.

## Q11 — Оқиға тред
**Мақсат: лайк, дәйексөз**

Басы, өрлеуі, бұрылысы бар нақты оқиға. Ойдан шығарма — жалғаны бірден
көрінеді.

```
1-пост: {оқиғаның ортасынан баста, ең қызық сәттен}
---
2-пост: {қалай осында келдім}
---
3-пост: {бұрылыс}
---
Соңғы: {не қалды}
```

## Q12 — Қалай істедім
**Мақсат: репост**

Өзің істеген, қайталауға болатын процесс. Теория емес, өз тәжірибең.

```
1-пост: {нәтиже, нақты санмен}. Қалай істегенімді жазайын.
---
2-пост: 1-қадам: {не істедім, не қиын болды}
---
...
Соңғы: {қайталағысы келгенге ескерту}
```

## Q13 — Қызығушылық үзігі
**Мақсат: жауап**

Күтпеген нәтижені айтасың, себебін бірінші постта ашпайсың.

```
1-пост: {күтпеген нәтиже}. Себебі мүлдем басқа нәрседе болып шықты.
---
2-пост: {не деп ойладық}
---
3-пост: {шын себеп}
```

**Қателік:** үзікті жалған жасама. Шешім шынымен күтпеген болуы керек,
әйтпесе оқырман алданғанын сезеді де, келесі тредіңді ашпайды.

# Бірінші жол ережелері

Threads лентада ұзын постты кеседі. Кескенге дейін көрінетін жер — шамамен
**бірінші 100-140 таңба** (құрылғыға байланысты). Қазақ тілінде бұл ~12-16
сөз.

- Бірінші сөйлемді 6-10 сөзге сыйғыз.
- Қазақ тілі SOV: етістік соңында тұрады. Ұзын сөйлемде мағына кесіндіден
  тыс қалады. Сондықтан **қысқа сөйлем** — тек стиль емес, механика.
- Кіріспе жазба. «Бүгін бір нәрсе туралы айтқым келеді» — 40 таңба ысырап.
- Сан немесе нақты зат бірінші жолда тұрсын.

# Ешқашан істемейтін нәрсе

- **Екі хэштег.** Threads екіншісін алып тастайды.
- **Бірінші постта сілтеме.** Қамтуды төмендетеді. Тредтің 2-постына қой.
- **«Түсініктемеге жаз!» деп сұрау.** Threads мұндай шақыруды төмендетеді.
  Оның орнына шын ашық сұрақ қой.
- **Мақалдан бастау.** Оқырман нақты ой күтеді, ал мақал жалпылама естіледі.
