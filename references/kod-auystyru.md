# Кодты ауыстыру: қазақша-орысша-ағылшынша араласқанда

## Мәселе

Қазақстандық аудиторияға арналған контент таза әдеби қазақ тілінде де,
таза орысша да жазылмайды. Нақты адам «дедлайнға үлгермедік» дейді,
«мерзімге үлгермедік» демейді. Бірақ шекара бар: **лексиканы араластыруға
болады, грамматиканы — жоқ.**

## Негізгі ереже

> Сөзді ал, грамматиканы алма.

Кірме сөз қазақ грамматикасына бағынуы керек: қазақша жалғау, қазақша сөз
тәртібі, қазақша етістік.

| | Мысал |
|---|---|
| ✅ Дұрыс | «Фичаны кеше шығардық.» |
| ❌ Грамматика бұзылған | «Фичаны кеше выкатили.» |
| ❌ Күштеп аударылған | «Мүмкіндікті кеше таратуға шығардық.» |

Ортаңғы жол — біріншісі.

## Қай сөзді аудармау керек

Сала ішінде тұрақталған терминді аударма. Аудармаң оқырманды тоқтатады, ол
«не туралы айтып тұр?» деп ойлануға мәжбүр болады.

**IT / стартап:** дедлайн, релиз, фича, баг, продукт, стартап, инвестор,
раунд, питч, юзер, фидбек, апдейт, деплой, бэклог, спринт, митап, оффер.

**Маркетинг:** контент, охват (қамту деуге болады), таргет, лид, воронка,
креатив, инсайт, бренд, конверсия.

**Күнделікті:** такси, кофе, скрин, сторис, рилс, подкаст, чат.

## Қай сөзді аудару керек

Қазақшасы бар әрі тірі қолданыстағы сөзді орысша қалдыру — жалқаулық белгісі.

| Орысша қалдырма | Қазақшасы тірі |
|---|---|
| вопрос | сұрақ |
| ответ | жауап |
| проблема | мәселе |
| решение (шешім мағынасында) | шешім |
| результат | нәтиже |
| опыт | тәжірибе |
| команда (адамдар) | команда — қалады, бірақ «топ» та жүреді |
| цель | мақсат |
| причина | себеп |
| пример | мысал |

Ереже: **күнделікті ұғым қазақша, сала термині сол күйі.**

## Жалғау қалай жалғанады

### Латын әрпімен жазылған сөз — дефис арқылы

> AI-ды, PR-ы, IT-ге, UX-ті, Threads-ке, API-мен

Дефиссіз жазу (`AIды`, `Threadsке`) — қате әрі оқылмайды.

### Кириллмен жазылған кірме сөз — тікелей

> дедлайнға, фичаны, релизден, продуктпен

### Дауысты үндестік

Кірме сөзге жалғау сөздің **соңғы буынының** дауыстысына қарай таңдалады,
түпнұсқа тіліне емес.

| Сөз | Дұрыс | Бұрыс |
|---|---|---|
| дедлайн | дедлайн**ға** | дедлайнге |
| релиз | релиз**ге** | релизға |
| продукт | продукт**і**, продукт**ке** | продуктқа |
| стартап | стартап**қа** | стартапке |
| фидбек | фидбек**ке** | фидбекқа |

Күмәндансаң: сөзді дауыстап айт, қай жалғау ыңғайлы естіледі — сол дұрыс.

### Аббревиатура

Оқылу тәсілі бойынша:

> МӘМС-ке (эм-ә-эм-эс), ЖШС-нің, IT-ге (ай-ти), AI-дың (эй-ай)

## Қанша орысша сөз көп?

Механикалық шек жоқ, бірақ практикалық бағдар:

- **1-3 кірме термин** — қалыпты, тірі сөйлеу тілі.
- **Сөйлем сайын бір термин** — оқырман шаршайды.
- **Етістіктер орысша** («сделали», «запустили») — бұл енді кодты ауыстыру
  емес, тілді ауыстыру. Постты қайта жаз.

Тексеру: `lib/emle.py` мәтіндегі қазақ әріптерінің үлесін өлшейді. 3%-дан
төмен түссе, ол мәтін іс жүзінде қазақша емес.

## Аудиторияңды таңда

Бір постта бір регистр:

| Аудитория | Регистр | Мысал |
|---|---|---|
| Стартап, IT | еркін кодты ауыстыру, «сен» | «Фичаны шығардық. Юзерлер қуанды.» |
| Жалпы бизнес | шамалы кірме сөз, «сіз» | «Жаңа қызметті іске қостық.» |
| Мемлекеттік/ресми | кірме сөз аз, «сіз» | ресми тіл, бірақ кеңсе тілінсіз |
| Мәдениет, білім | таза қазақша, «сен» не «сіз» | терминді де қазақшала |

Регистрді ортасында ауыстырма — бұл ең байқалатын жасандылық.
